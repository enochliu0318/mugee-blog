# Markdown 详细使用手册

> 本手册全面覆盖 Markdown 的基础语法、扩展语法（以 GitHub Flavored Markdown / CommonMark 为主）、最佳实践与常用技巧，适合初学者系统学习，也适合作为速查手册使用。

test2

## 1. 什么是 Markdown

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年创建。它的目标是：**让文档既易于阅读又易于书写**，同时可以轻松转换为 HTML、PDF 等格式。

Markdown 文件通常以 `.md` 或 `.markdown` 为扩展名。

**核心优势：**
- 语法简单，学习成本低
- 纯文本，跨平台、易版本控制（Git 友好）
- 可读性极高（即使不渲染也能看懂）
- 广泛支持（GitHub、GitLab、Notion、Typora、VS Code、Obsidian、掘金、知乎等）

## 2. 基础语法

### 2.1 标题

使用 `#` 号表示标题，一级标题用一个 `#`，二级用两个，最多支持六级。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

**渲染效果：**

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

> **注意：** `#` 与标题文字之间必须有一个空格。

也支持使用 `===` 和 `---` 的 Setext 风格（较少使用）：

```markdown
一级标题
========

二级标题
--------
```

### 2.2 段落与换行

- 段落之间用**空行**分隔。
- 同一段落内换行：在行尾加**两个空格**再回车，或直接使用 HTML 的 `<br>`。

```markdown
这是第一段。

这是第二段。
这是第二段的第二行（行尾加了两个空格）。  
这是强制换行后的内容。
```

### 2.3 强调（粗体、斜体、删除线等）

| 效果       | 语法                  | 示例代码                  | 渲染结果          |
|------------|-----------------------|---------------------------|-------------------|
| 斜体       | `*文本*` 或 `_文本_`  | `*斜体*`                  | *斜体*            |
| 粗体       | `**文本**` 或 `__文本__` | `**粗体**`              | **粗体**          |
| 粗斜体     | `***文本***`          | `***粗斜体***`            | ***粗斜体***      |
| 删除线     | `~~文本~~`            | `~~删除线~~`              | ~~删除线~~        |
| 下划线     | 使用 HTML `<u>`       | `<u>下划线</u>`           | <u>下划线</u>     |

**示例：**

```markdown
这是 *斜体*，这是 **粗体**，这是 ***粗斜体***，这是 ~~删除线~~。
```

### 2.4 列表

#### 无序列表

使用 `-`、`*` 或 `+`（推荐统一使用 `-`）。

```markdown
- 项目一
- 项目二
  - 子项目 2.1
  - 子项目 2.2
- 项目三
```

#### 有序列表

使用数字 + 英文句点。

```markdown
1. 第一项
2. 第二项
3. 第三项
   1. 子项 3.1
   2. 子项 3.2
```

> 数字不一定要按顺序写，渲染时会自动连续编号，但为了可读性建议按顺序写。

#### 嵌套列表

通过缩进（通常 2 或 4 个空格）实现嵌套。

### 2.5 链接

#### 行内链接

```markdown
[链接文字](https://www.example.com)
[带标题的链接](https://www.example.com "鼠标悬停显示的标题")
```

#### 引用式链接

```markdown
[链接文字][id]

[id]: https://www.example.com "可选标题"
```

#### 自动链接

直接写 URL 或用尖括号：

```markdown
https://www.example.com
<https://www.example.com>
```

#### 相对路径链接（文档内部）

```markdown
[跳转到目录](#目录)
[打开同目录下的文件](./another.md)
```

### 2.6 图片

语法与链接类似，只是前面多一个感叹号 `!`。

```markdown
![替代文本](图片地址)
![替代文本](图片地址 "可选标题")
```

**示例：**

```markdown
![Markdown Logo](https://markdown-here.com/img/icon256.png "Markdown")
```

也可以使用引用式：

```markdown
![替代文本][logo]

[logo]: https://example.com/logo.png "Logo"
```

### 2.7 引用

使用 `>` 表示引用块，可嵌套。

```markdown
> 这是一段引用。
>
> 引用可以有多段。
>
> > 这是嵌套引用。
```

**渲染效果：**

> 这是一段引用。
>
> 引用可以有多段。
>
> > 这是嵌套引用。

### 2.8 代码

#### 行内代码

使用反引号 `` ` ``：

```markdown
使用 `console.log()` 输出信息。
```

#### 代码块

使用三个反引号 ```，并可以指定语言实现语法高亮：

````markdown
```javascript
function hello() {
  console.log("Hello, Markdown!");
}
```
````

也支持用四个空格缩进表示代码块（不推荐，无法指定语言）。

### 2.9 分隔线

使用三个及以上的 `-`、`*` 或 `_`（中间可有空格）：

```markdown
---
***
___
```

## 3. 扩展语法（GFM / 常用扩展）

### 3.1 表格

GitHub Flavored Markdown 支持表格。

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
| :----- | :------: | -----: |
| 单元格 |  单元格  | 单元格 |
| 长文本 |   内容   |  数字  |
```

**渲染效果：**

| 左对齐 | 居中对齐 | 右对齐 |
| :----- | :------: | -----: |
| 单元格 |  单元格  | 单元格 |
| 长文本 |   内容   |  数字  |

- `:---` 左对齐
- `:---:` 居中
- `---:` 右对齐
- 表头与内容之间必须有分隔行

### 3.2 任务列表（待办事项）

```markdown
- [x] 已完成任务
- [ ] 未完成任务
- [ ] 另一个待办
```

**渲染效果：**

- [x] 已完成任务
- [ ] 未完成任务
- [ ] 另一个待办

### 3.3 删除线

```markdown
~~这段文字被删除了~~
```

### 3.4 自动链接与 URL

GFM 会自动把符合规则的 URL 和邮箱变成链接：

```markdown
访问 https://github.com 或发送邮件到 example@email.com
```

### 3.5 脚注

部分解析器支持（如 Pandoc、部分静态站点生成器）：

```markdown
这里有一个脚注[^1]。

[^1]: 这是脚注的内容。
```

### 3.6 定义列表

部分扩展支持：

```markdown
术语 1
: 定义 1

术语 2
: 定义 2
: 定义 2 的另一条
```

### 3.7 Emoji 表情

GitHub 等平台支持：

```markdown
:smile: :heart: :rocket: :warning:
```

也可以直接复制粘贴 Unicode 表情 😀 ❤️ 🚀

### 3.8 数学公式

很多平台（GitHub、Notion、Obsidian、Typora 等）支持 LaTeX 数学公式。

**行内公式：**

```markdown
质能方程式：$E = mc^2$
```

**块级公式：**

```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```

### 3.9 高亮与标记

部分扩展支持 `==高亮==`：

```markdown
这是 ==高亮文本==。
```

### 3.10 HTML 嵌入

Markdown 支持直接嵌入 HTML 标签：

```markdown
<details>
<summary>点击展开</summary>

这里是折叠的内容。

</details>

<kbd>Ctrl</kbd> + <kbd>C</kbd>
```

## 4. 进阶技巧与最佳实践

1. **保持一致性**：统一使用 `-` 做无序列表，统一标题层级风格。
2. **空行很重要**：标题前后、列表前后、代码块前后建议留空行，兼容性更好。
3. **尽量少用 HTML**：除非 Markdown 无法实现（如复杂表格、折叠、居中等）。
4. **图片建议使用相对路径**或图床，方便迁移。
5. **长文档使用目录**：像本手册一样，用锚点链接做目录。
6. **代码块务必指定语言**，方便语法高亮。
7. **避免过度嵌套**：列表嵌套不要超过 3 层，可读性会下降。
8. **使用引用式链接**管理大量链接，方便维护。
9. **文件命名**：推荐使用小写字母、连字符，如 `markdown-guide.md`。
10. **版本控制友好**：Markdown 与 Git 绝配，diff 清晰。

## 7. 常见问题与注意事项

1. **为什么我的表格没渲染？**  
   检查是否有空行、分隔行是否正确、单元格内是否有未转义的 `|`。

2. **标题锚点怎么生成？**  
   大多数平台会把标题转成小写、空格变 `-`、去掉特殊字符。中文标题在不同平台规则略有差异。

3. **如何在列表中写代码块？**  
   代码块需要相对列表项多缩进 4 个空格（或一个 Tab）。

4. **Markdown 能做幻灯片吗？**  
   可以，使用 Marp、Slidev、reveal.js 等工具。

5. **导出 PDF 推荐工具？**  
   Typora 自带、Pandoc + XeLaTeX、VS Code 插件、或在线工具。

6. **标准是什么？**  
   - 最基础：John Gruber 原版  
   - 现代通用：CommonMark  
   - 最流行扩展：GitHub Flavored Markdown (GFM)
